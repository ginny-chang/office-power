# 版面

## 骨架

- **左側導覽列**：WorkspaceRail，80px 寬、`frame` 底，`z-index:50`，蓋在子頁面（`z-index:40`）之上。
- **第一層頁面的主內容**：放在 `canvas` 上，填滿導覽列右側的寬度，不設最大寬，左右都是 `sp-6` 24px。
- **子頁面的主內容**：新增 Agent 和第一層一樣填滿寬度；排程與 Agent 設定目前是最大寬約 1200px 置中。
- **頁首**：PageTitle 貼齊頂端；頁面層級的搜尋框放在同一列右下，寬度對齊最右欄；頁首到內容 24px。
- **頁面層級的新增按鈕**：一律靠右，對齊內容區右緣；分頁或篩選放在同一列左邊。
- **卡片標題不加 icon**：全站區塊標題只有文字（`t-title`）。

## 子頁面頁首

排程、Agent 設定、NOVA App 詳細頁、新增 Agent 都一樣：

1. 返回連結 `‹ 上一頁名稱`：寫實際頁名，不寫「返回」。`ChevronLeft` 16px、`t-label` 500、`ink-2`，高 28px，下方 16px。
2. 一列：左邊大標（可帶一行說明），右邊動作按鈕，間距 8px，底部對齊。
3. 動作由左到右：`刪除` → `立即執行` 等次要動作 → `儲存` → `預覽` → `發佈`。

## 雙欄詳細頁

左右兩張白卡，中間 24px 是可拖拉的分隔條。內容較多的卡片自行捲動，頁面本身不捲。

## 窄螢幕

寬度 ≤ 900px 時雙欄改單欄，分隔條隱藏，不可有水平捲動。

## Agent 設定的兩種開法

從 My Board 進入是子頁面；從其他流程（新增 Agent 完成後、用量與費用、Runtime 管理）開是同一份內容的置中對話框，關閉後回到原本的頁面。

## 帳號與權限

- 帳號選單只放名稱、Email、檢視身份、「設定」與「登出」，不加 icon。介面語言放在設定頁。
- Admin 專屬功能（上下架 App、能力中心、Organization、用量與費用）對一般使用者整個隱藏，不是 disabled。
