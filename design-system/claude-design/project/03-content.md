# 文案與狀態

## 文案

- **動詞統一**：`發佈`（不是發布）；按鈕用 `新增`（不是建立），唯一例外是「確認 Blueprint 並建立 Agent」，說明文字可以寫「建立」；`儲存`；連到另一頁的文字連結叫 `前往`。
- **介面文字用繁體中文**：稽核紀錄、設定、檔案與知識庫、技能，不混英文，也不寫「外觀主題 Theme」這種雙語。
- **可以保留英文的**：產品與頁面名（My Board、Chat、NOVA Apps、Organization、Account）、專有名詞（Agent、Blueprint、MCP、Token、System Prompt、Timeline、Gateway、Runtime）。
- **不放**示範標籤、操作提示小字，或「2/2」這種步驟計數；進度文字「第 N 題 / 共 4 題」是唯一例外。
- **錯誤訊息**用白話寫清楚下一步，不直接顯示技術訊息。例如「這個 Email 格式不正確，請檢查 @ 後面的網域。」
- **返回連結**寫上一頁的實際名稱，例如「‹ My Board」。
- **金額單位**寫在 label 後面：「費用（USD）」。

## 狀態與互動

- 每個畫面都要有：預設、hover、focus、disabled、空狀態（一句話加一個主要動作）；有非同步的再加 loading 與錯誤。
- **儲存**：和載入時的內容比較，沒變就 disabled。「發佈」會直接帶目前內容儲存並發佈。
- **失敗**要有下一步：重新執行或前往修正。
- **刪除**一定先開確認對話框，Agent 設定的第一個動作是 `刪除`（灰框紅字、`Trash2`）。大腦總管 NOVA 不能刪除，也不顯示按鈕。
- **權限**：Admin 專屬功能對一般使用者整個隱藏，不是 disabled。
- **轉場**只改顏色與底色。
