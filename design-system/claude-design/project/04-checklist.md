# 禁止事項與交付檢查

## 禁止事項

1. 不寫死色碼、字級、間距；只用 token（`#2c2c30` 與 `#b8262b` 兩個 hover 色例外）。
2. 不出現 `r` 12px 以外的圓角，不做 pill 形狀（狀態燈號與進度點除外）。
3. 不用陰影堆疊做層次；卡片沒有邊框。
4. 不新增按鈕層級或第四種高度；不用 `lime` 或其他顏色當按鈕底色。
5. `danger` 只給刪除、失敗與數值下降。
6. 不用顏色單獨表示狀態。
7. 同一份清單不同時有兩列 active，hover 和 active 不用不同底色。
8. 卡片上不放「編輯」，整張卡就是入口。
9. 需要捲動、多欄或多步驟的流程不塞進對話框。
10. 不放示範標籤、操作提示小字。
11. 欄位 focus 不加粗邊框或換框色，只有變白加 `focus-ring`。
12. 不用 `ink-3` 寫要讀懂才能操作的文字。
13. 不新增字級；不用 16、20、24、32px 以外的 icon。
14. 一行內容的欄位不用 textarea。

## 交付前自我檢查

- 顏色、間距、字級、圓角都是 token？
- 輸入框 44px；按鈕是 44、36、28 其中之一，且符合擺放位置？
- 區域裡只有一個 primary；取消是 ghost；刪除是灰框紅字且有確認？
- 頁首和表單的動作按鈕都有 16px icon？
- 儲存按鈕在沒有變更時是 disabled？
- 欄位與搜尋 focus 都是白底加外環，外環在最外層？
- 清單只有一列 active？
- 狀態都有文字或 icon？成功和上升是 `mint`，失敗和下降是 `danger`？
- 卡片標題是 `t-title`、無字距、前面沒有 icon？
- icon 與 Icons 對照表一致？
- 文案是「發佈」「新增」「儲存」「前往」，沒有混英文？
- 下拉與 popover 沒有被裁切或超出畫面？
- 間距都在 4px 格線上？
- 有空狀態；Admin 功能對一般使用者隱藏？
- ≤ 900px 時雙欄改單欄、沒有水平捲動？

## 刻意保留的例外

這些是目前刻意保留的，不要自行「修正」，也不要照著擴散到新畫面：

- **App 預覽畫面**維持各 App 自己的深色主題，不套本系統的欄位、focus 與色彩。
- **App 類型與 Agent 的彩色圖示**使用 `type-*`，App 類型 icon 另有漸層，是全站唯一可以用漸層和額外色相的地方。
- **Organization 的「停用」**是紅字灰框，雖然不是刪除，目前保留。
- **NOVA App 詳細頁頁首**沒有 40px 大標和儲存、發佈：返回連結下方是可直接編輯的圖示、名稱（`t-title`）與說明，修改即時保存。
- **費用上升也是綠色**：較上期統一是上升綠、下降紅。
- **外觀主題色票**：設定頁的主題預覽色票是固定色值，才能在任何主題下預覽各自的配色。
