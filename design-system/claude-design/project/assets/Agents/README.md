# Agents

14 個 Agent 角色的頭像 PNG，AgentAvatar 依 Agent 的名稱或角色挑其中一張。

- `nova.png`：大腦總管 NOVA，白色機器人，負責調度。
- `command.png`、`app-helper.png`、`planner.png`：NOVA 的三個分身：指令中心、App 產生與修改、專案助理。
- `attendance.png` 出勤假勤、`equipment.png` 設備維修、`product.png` 產品開發、`project.png` 專案管理、`sales.png` 業務接待、`hr.png` 人資、`design.png` 設計內容、`life.png` 生活福利、`finance.png` 財務、`general.png` 通用。

頭像以 `r` 圓角方塊或圓形顯示，常用 22、32、44px。同一個 Agent 全站同一張，不換成 emoji 或其他圖示。
